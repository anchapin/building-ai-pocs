## 0. Environment & method notes

- Worker sandbox: python3 + curl via the egress proxy; USGS TNM API and the Microsoft
  Building Footprints tile host were reachable; several reference sites (loc.gov)
  returned 503 through the proxy.
- Method: per building, a TNM `products` query over a ±0.0015° bbox around the
  building's coordinates (`queries/tnm_lpc_<tag>.json`), and a point-in-polygon test
  against the Microsoft Building Footprints quadkey tile `032010221`
  (`queries/coverage_results.json`, generated by `scripts/coverage_gate.py` from
  `scripts/buildings.json`). The raw quadkey tile (39 MB .csv.gz, md5
  816f078259f7b95e8e1650bf5329554d) was downloaded once per building by the worker —
  five identical copies; the duplicates were removed at collection and only the
  extracted covering features are retained in `coverage_results.json`.
- Overture Maps was NOT queried: its buildings release ships as ~510–550 MB
  non-spatial parquet partitions, outside this Phase 0 download budget. The issue's
  wording allows "Overture / Microsoft", so Microsoft Building Footprints is the
  footprint source of record here. [inference: Overture's buildings theme itself
  incorporates Microsoft footprints as a source.]

### 1.1 USGS 3DEP LPC tile coverage per building

Every candidate is covered by the 2019/2020 project `VA_SouthamptonHenricoWMBG_2019_B19`
(published 2020-12-21; tiles 15.6–21.1 MB LAZ via rockyweb.usgs.gov) and by the older
`Virginia_SANDY_QL2_LiDAR` (2015). Full tile titles, URLs, dates and sizes are in
`queries/tnm_lpc_<tag>.json` and summarised in `queries/coverage_results.json`.
LiDAR coverage: **5/5 usable**.

### 1.2 Footprint presence — Microsoft Building Footprints

Point-in-polygon against quadkey `032010221`: a footprint polygon covers the
building's reference point for 3 of 5 (Capitol, 600 Canal Place, Main Street Station).
For the James Monroe Building and the Federal Reserve Bank Building, 0 polygons cover
the exact reference point — that is **not** proof of absence (a reference point can sit
on a plaza, setback, or tower offset outside the polygon); a bbox/nearest-feature
search was not completed before the step cap, so these two are recorded as
NOT CONFIRMED, not absent.

### 1.3 Kill bar applied

The #64 kill bar: fewer than 4 of 5 sites with usable LiDAR + footprints = Phase 0
No-go on data availability. Measured: LiDAR 5/5; footprints confirmed 3/5, unconfirmed
2/5; published references 0/5 recorded. The bar therefore **cannot be certified either
way from this evidence**: the gate does not pass (only 3 confirmed), and a No-go is
not warranted (the 2 unconfirmed are a method limit, not an absence finding). The
remaining gate work is small and specific: a bbox/nearest-feature footprint check for
the 2 unconfirmed buildings, and recording the published references.
